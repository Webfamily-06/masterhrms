# React Jampack Classic

React Jampack Classic is a Bootstrap 5, React-Bootstrap, Vite, TanStack Router admin template prepared for production packaging and ThemeForest-style buyer delivery.

The template keeps the original Classic Jampack layout, SCSS, assets, Header, Sidebar, Footer, and ClassicLayout structure. Routing is organized with TanStack Router file-based routes, and the app includes TanStack Query, TanStack Table, and TanStack Form packages for modern React data workflows.

## Requirements

- Node.js `20.19.0` or newer. Node `22.12.0+` is also supported.
- npm `10+` recommended.

## Quick Start

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Available Scripts

```bash
npm run dev
npm run start
npm run build
npm run preview
npm run lint
```

- `npm run dev` starts the Vite development server.
- `npm run start` starts Vite with host access.
- `npm run build` creates the production build in `dist/`.
- `npm run preview` previews the production build locally.
- `npm run lint` checks source quality with ESLint v9 flat config.

## Project Structure

```text
src/
  assets/       Preview images, logos, icons, and static media
  components/   Reusable Jampack UI and utility components
  layout/       Header, Sidebar, Footer, and Classic layout shell
  redux/        Existing Redux actions, reducers, and store
  routes/       TanStack Router file-based route modules
  styles/       Bootstrap-based SCSS, CSS, fonts, and theme styles
  utils/        Theme provider and router compatibility helpers
  views/        Dashboard, apps, pages, auth, and feature views
```

## Routing

Routes are file-based with TanStack Router and generated into `src/routeTree.gen.ts`. Do not manually edit `src/routeTree.gen.ts`; it is generated by the TanStack Router Vite plugin.

Examples:

- `/dashboard`
- `/apps/chat/chats`
- `/apps/email`
- `/pages/profile`
- `/auth/login`

## Styling

This package intentionally uses Bootstrap, React-Bootstrap, and the existing SCSS design system. Do not remove Bootstrap classes or replace React-Bootstrap components if you want to preserve the supplied UI.

## Production Build

```bash
npm ci
npm run lint
npm run build
```

Deploy the generated `dist/` folder to any static hosting provider. Configure the host to serve `index.html` for deep links because this is a client-side routed app.
