## 1. Visual & Design System Alignment

The fifth HR Leave Management page (**Leave Encashment & Comp-Off**) was implemented to match the four existing Leave pages (*Leave Applications*, *Leave Balances*, *Leave Types*, *Leave Policies*) across every visual and interaction detail:

- **Typography & Spacing:** `text-xl font-bold tracking-tight` page title, `text-xs text-slate-500` subtitle, compact `h-9 text-xs` controls, `rounded-xl` cards (`border-slate-200/80 dark:border-slate-800 shadow-xs`).
- **Brand Action Color:** Primary CTA buttons use `#00a76f` (`hover:bg-[#008f5d] text-white`).
- **Dark Mode Support:** Full `dark:bg-slate-900`, `dark:border-slate-800`, `dark:text-slate-100`, and semantic dark badge contrasts across every card, table, filter, and modal.
- **Responsive Mobile Layouts:** Desktop viewports (`md:block`) render high-density enterprise tables while mobile viewports (`md:hidden`, e.g., `390x844`) render stacked action cards with zero horizontal overflow (`max-w-full overflow-x-hidden`).
- **Zero Redesigned Existing Pages:** *Leave Applications*, *Leave Balances*, *Leave Types*, and *Leave Policies* remain untouched in visual design, while *Leave Overview* hubs (`/hr/leave` & `/me/leave`) gained the 5th module card.

## 3. HR Workspace Page (`/hr/leave/encashment-compoff`)

### 3.1 Header & Dynamic Server-Aggregated Summary Cards
- **Header Actions:** `Refresh`, `Add Comp-Off Request` (gated by `viewerAccess.canCreateCompOff`), and `Add Encashment Request` (gated by `viewerAccess.canCreateEncashment`).
- **6 Dynamic Summary Cards (`GET /api/v1/hr/leave/encashment-compoff/summary`):**
  1. `Pending Encashments`
  2. `Approved Encashments` (with approved day count)
  3. `Awaiting Payroll` (with dynamic tenant-currency total for authorized viewers)
  4. `Pending Comp-Offs`
  5. `Available Comp-Off Days` (live non-expired FIFO balance)
  6. `Expiring Comp-Off Days` (within configurable warning window)

### 3.2 Server-Side Filter, Search, Sort & Pagination Bar
All dropdown options are loaded dynamically from `GET /api/v1/hr/leave/encashment-compoff/metadata`:
- Debounced Search (`requestCode`, employee name/code, reason)
- Employee, Department, Branch, Leave Type, Request Status
- Date Range (`From` / `To`)
- Payroll Period (`Payroll Month` & `Payroll Year`)
- Transaction Type (`ENCASHMENT` / `COMP_OFF`)
- Sort Field (`createdAt`, `effectiveDate`, `workedOnDate`, `days`, `netPayableAmount`, `status`) + `ASC`/`DESC` toggle + Page size (`10`, `12`, `20`, `50`) & Previous/Next server pagination.

### 3.3 Four Operational Tabs
1. **Encashment Tab:**
   - Displays request code, employee avatar/code/department, leave type color indicator, requested/approved days, retained balance snapshot, dynamic currency payout & unit daily rate (redacted as *Restricted* for non-HR/Payroll managers), workflow/payroll status badges, and contextual actions (`Approve`, `Reject`, `Clarify`, `Queue Payroll`, `Mark Paid`, `Fail`, `Reverse`, `Edit`, `Cancel`, `View Detail`).
2. **Comp-Off Tab:**
   - Displays request code & worked date, employee, work category (`Weekly Off`, `Public Holiday`, `Overtime`) + verified hours, credited days, live FIFO lot utilization (`Available`, `Used`, `Expired`), expiry date, status badge, contextual actions, and HR Admin `Run Expiry Sweep` button.
3. **Transaction History Tab:**
   - Unified server-paginated ledger of all `ENCASHMENT` and `COMP_OFF` transactions with **Export CSV** and **Export JSON** actions backed by `/api/v1/hr/leave/encashment-compoff/transactions/export` and full **Audit Trail** inspection dialog.
4. **Configuration Tab:**
   - Dual-policy management (`Leave Encashment Policies` & `Comp-Off Policies`) displaying version badges (`v1`, `v2`), effective windows, salary basis/divisor or hour-conversion rules, and HR-Admin-gated Create / Edit / Deactivate operations.

### 3.4 Interactive Modals & Rich Detail Dialog
- **Create / Edit Encashment Modal:** Calls `GET /encashments/eligible-types` per employee and `POST /encashments/calculate-preview` for real-time authoritative payout, divisor source, and retained-balance preview + supporting document upload.
- **Create / Edit Comp-Off Modal:** Calls `POST /comp-offs/verify-eligibility` to verify holiday/weekly-off calendar, attendance punches, and approved overtime + supporting proof upload.
- **Contextual Workflow Dialog:** Enforces mandatory rejection/failure/reversal audit notes, payroll period & earning head mapping on `Queue Payroll`, and verified payroll run/disbursement reference on `Mark Paid`.
- **Rich Transaction Detail Dialog:** Renders employee & financial/work summary, linked immutable `LeaveLedgerEntry` rows, `CompOffUsageAllocation` leave consumption records, and chronological `LeaveEncashmentCompOffEvent` timeline.

## 4. Employee Self-Service & Manager Portal (`/me/leave/encashment-compoff`)

Implemented identically in both Next.js CMS and TanStack Start:
- **Expiring Comp-Off Banner:** Alerts employees when FIFO lots approach expiration with a direct CTA to `/me/leave/applications`.
- **4 Dynamic Summary Cards:** Available Comp-Off Balance, Expiring Soon, Pending Requests, Eligible Encashment Types.
- **ESS Tabs:** `My Encashment Requests`, `My Comp-Off Requests`, `Eligible Quotas & FIFO Lots`, and dynamic `Team Approvals` tab for Reporting Managers (`directReportsCount > 0`) with salary redaction preserved.
- **ESS Leave Application Integration:** Existing `/hr/leave/applications` and `/me/leave/applications` seamlessly display Comp-Off leave types from `/api/v1/me/leave/catalog`, run FIFO lot & expiry validation on dry-run/submit, deduct FIFO lots on approval, and restore lots on cancellation.
