## 2. Architecture & Security Specifications
1. **Multi-Tenant Scoping:** Credentials (OAuth access tokens, API keys, webhook URLs) stored encrypted via `SettingsService` under `integration.connector.external-gateways` with `TENANT` isolation.
2. **Deterministic Sandbox & Live Dual-Engine:**
   - Sandbox mode executes realistic deterministic simulations without requiring live 3rd-party credentials, generating reproducible IDs (`gcal_event_sim_*`, `jira_issue_sim_*`, `zapier_sim_*`, etc.).
   - Live mode dispatches authentic HTTP requests using Node.js native `fetch` when production credentials are configured.
3. **Audit Logging:** Every event dispatch and sync attempt logged to tenant-scoped audit memory buffer and persistent audit logs.
4. **Zero Secret Leakage:** Configuration retrieval endpoints mask API secrets, private keys, and OAuth tokens before responding.
