# Phase 10 Plan: Internal WorkDo Add-on Modules Verification (Wave 2: Communication, Productivity & Mobility)

## Goal
Empirically verify 10 internal WorkDo add-on modules currently categorized as `PLANNED` across File Sharing, Document Types & Templates, Quotations, Contact Management, Email Box, Call Hub, Meeting Hub, Rotas & Shift Management, Project Template, and Custom Alert by authoring and executing comprehensive native automated test suites (`node:test` + `node:assert/strict`), promoting all 10 items to `VERIFIED` (Milestone 7.5).

## Target Scope & Requirements

1. **REQ-W2-01 (`ADDON-053` - File Sharing)**:
   - File permission hierarchy: `VIEWER` (1), `EDITOR` (2), `MANAGER` (3), `OWNER` (4).
   - Zero-byte file entity linking (`FileLinkService.createLink`) to expenses, CRM, employee KYC without duplicating bytes.
   - Multi-tenant isolation: Cross-tenant access strictly blocked with fail-closed 403.

2. **REQ-W2-02 (`ADDON-073` - Document Types & Templates)**:
   - Default standard document types seeding (`DEFAULT_STANDARD_DOCUMENT_TYPES` with Aadhaar, PAN, Passport, Education, Relieving Letter, etc.).
   - Required vs Optional categorization.
   - DocumentType CRUD operations and strict multi-tenant boundary.

3. **REQ-W2-03 (`ADDON-074` - Quotation / CRM Proposals & Sales Invoicing)**:
   - Proposal creation with auto-generated `proposalNo` (`PROP-YYYY-XXXX`), line items, client details, and amount.
   - Proposal status lifecycle transitions (`draft` -> `sent` -> `accepted` -> `converted`).
   - One-click conversion from proposal to formal Sale record (`/api/crm/proposals/:id/convert`).
   - Public client acceptance / digital signature support.

4. **REQ-W2-04 (`ADDON-078` - Contact Management / CRM Contacts & Clients)**:
   - Contact creation, retrieval, update, and deletion (`CrmContact`).
   - Contact attributes: name, company, email, phone, stage, notes, tags.
   - Multi-tenant query isolation.

5. **REQ-W2-05 (`ADDON-102` - Email Box / User Email Accounts)**:
   - User email account management with AES-256-GCM encrypted credentials for IMAP and SMTP.
   - Inbound protocols (IMAP/POP3) and outbound SMTP security levels (SSL/TLS, STARTTLS).
   - Email status verification and tenant-aware outbound gateway configuration.

6. **REQ-W2-06 (`ADDON-104` - Call Hub)**:
   - Direct and group VoIP/WebRTC call session lifecycle (`RINGING` -> `ACTIVE` -> `ENDED`).
   - Participant heartbeat tracking with atomic JSONB metadata merge (`recordHeartbeat`).
   - Serverless-safe stale session reaper (`reapStaleSessions`) cleaning orphaned calls and dead participants.
   - Multi-tenant call isolation.

7. **REQ-W2-07 (`ADDON-113` - Meeting Hub)**:
   - Meeting room management with capacity and amenities.
   - Meeting type masters with color-coded classification.
   - Meeting scheduling with date/room conflict prevention.
   - Meeting action items tracking with completion status.
   - Multi-tenant boundary isolation.

8. **REQ-W2-08 (`ADDON-117` - Rotas & Shift Management)**:
   - Standard shift definitions seeding (General, Morning, Evening, Night Differential, Weekly Off).
   - Shift definition creation with start/end time, breaks, allowances, and overtime flags.
   - Shift roster scheduling with employee assignment.
   - Peer shift swap request and manager decision workflow.
   - Multi-tenant boundary isolation.

9. **REQ-W2-09 (`ADDON-119` - Project Template)**:
   - Predefined project templates (Healthcare EPMS, Software Agile, HR Onboarding, Marketing Launch).
   - One-click project instantiation from template with automated milestone and task cloning.
   - Project milestone tracking and task kanban progression.
   - Multi-tenant boundary isolation.

10. **REQ-W2-10 (`ADDON-122` - Custom Alert)**:
    - Multi-channel notification engine (Slack, Telegram, WhatsApp, SMS) configuration.
    - High-value transaction and low-stock threshold alert triggers.
    - Contextual internal reminder creation with due dates, entity linking, and completion tracking.
    - Multi-tenant boundary isolation.
