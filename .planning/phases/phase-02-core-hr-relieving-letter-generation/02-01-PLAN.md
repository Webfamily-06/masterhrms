# Phase 2 Plan: Core HR & Formal Relieving Letter Document Generation (FN-057 / GAP-01)

## Goal
Resolve critical GAP-01 in `FN-057` by implementing formal Relieving Letter document rendering, digital metadata generation, cryptographic SHA-256 sealing, encrypted file storage, and downloadable retrieval upon Full & Final settlement completion.

## Architectural Requirements
1. **Relieving Letter Service (`server/src/services/relieving-letter.service.ts`)**:
   - Vector PDF rendering using `pdfkit`.
   - Generates official company relieving certificate with:
     - Tenant branding / Organization title.
     - Relieving Reference Code (e.g. `REL-7482`).
     - Employee particulars: Full name, Employee Code, Department, Designation, Date of Joining, Last Working Day, Exit Type.
     - Full & Final settlement amount and clearance confirmation across HR, IT, Finance, and Administration.
     - Formal certification text releasing employee from company obligations with good standing.
     - Digital signature block with verification hash (SHA-256) and timestamp.
   - Storage integration via `storageService.save(...)` in `StoredDocument` (AES-256-GCM encrypted).
   - Database record creation in `CompanyDocument` linked to `employeeId` with status `verified` / `issued`.
2. **Offboarding Route Integration (`server/src/routes/offboarding.routes.ts`)**:
   - Update `POST /api/offboarding/exits/:id/settle-fnf` to trigger `RelievingLetterService.generateAndStoreRelievingLetter(...)`.
   - Return relieving letter metadata (`downloadUrl`, `storedDocumentId`, `companyDocumentId`, `sha256Hash`, `fileName`) in the settlement API response.
   - Add `GET /api/offboarding/exits/:id/relieving-letter` endpoint to retrieve or download the generated letter for an exit case.
3. **Verification**:
   - Comprehensive test suite in `server/src/tests/relieving-letter-generation.test.ts` verifying:
     - PDF buffer generation with valid `%PDF` signature.
     - Encrypted storage persistence in `stored_documents`.
     - `CompanyDocument` persistence and retrieval.
     - Integration in `/api/offboarding/exits/:id/settle-fnf`.
   - TypeScript compilation check (`npx tsc --noEmit`).
