## Key Technical Objectives
1. **Unified Multi-Tenant Pluggable Architecture:**
   - Implement `ExternalGatewaysService` with dynamic configuration persistence per tenant under `integration.connector.external-gateways` via authoritative `SettingsService`.
   - Complete secret encryption (AES-256) and fail-closed secret masking for public endpoints.
2. **Dual-Mode Execution (Sandbox vs. Live):**
   - Every gateway supports deterministic sandbox simulation with mock identifiers for safe testing and staging.
   - When configured with live credentials, executes standard HTTP REST/webhook requests against upstream provider endpoints.
3. **Express Router Mounting:**
   - Mount `externalGatewaysRouter` in `server/src/index.ts` under `/api/external-gateways` and `/api/v1/external-gateways` with endpoints for config retrieval, credential updates, connection testing, outbound dispatches, and log audits.
4. **Empirical Automated Verification:**
   - Author and verify all 15 gateways in `server/src/tests/external-gateways.test.ts` with 100% test pass and zero failures.
