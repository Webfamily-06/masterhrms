# Phase 5 Plan: Marketplace & Modular Add-on Architecture Verification

## Goal
Verify the modular catalog, tenant entitlement gating, status transitions, and fail-closed security guards across all modular add-ons and products.

## Scope of Verification
1. **Catalog Integrity & Parity**:
   - Verify `CANONICAL_CATALOG_REGISTRY` in `server/src/services/unified-catalog.service.ts`.
   - Verify all product types: `BASE_PLAN`, `STANDALONE_PRODUCT`, `ADDON_FEATURE`, `ADDON_INTEGRATION`.
2. **Database Persistence**:
   - Verify `UnifiedCatalogService.ensureCanonicalAddonsInDb()` creates/syncs database records in the `Addon` table.
3. **Entitlement State Transitions**:
   - Verify `checkTenantEntitlement(tenantId, addonSlug)` correctly validates active status and denies access when disabled.
   - Verify multi-tenant isolation and fail-closed rejection.
