# Phase 3 Plan: Missing Route Endpoints Implementation (Workstream C / FN-041, FN-046, FN-055, FN-061)

## Goal
Implement the 4 missing and partially implemented endpoints identified during the forensic audit to achieve full WorkDo SaaS parity and contract compliance:
1. `FN-041`: `POST /api/crm/leads/:id/convert` (CRM Lead to Deal Conversion)
2. `FN-046`: `POST /api/addons/assets/:id/assign` and `POST /api/assets/:id/assign` (Asset Assignment & Custody Tracking)
3. `FN-055`: `PUT /api/expenses/:id/approve` and `POST /api/expenses/:id/approve` (Multi-Level Expense Approval)
4. `FN-061`: `PUT /api/super/tenants/:id/quota` and `GET /api/super/tenants/:id/quota` (Tenant Resource Quota Management)

## Implementation Details
1. **CRM Lead Conversion (`server/src/routes/crm.routes.ts`)**:
   - Route: `POST /api/crm/leads/:id/convert`
   - Permissions: `requireAuth`, `resolveTenantContext`, `requirePermission("crm.leads.edit")`
   - Atomic transaction creating `CrmDeal` linked to `lead.id` and marking `CrmLead` stage as `converted`.
   - Real-time tenant notification: `broadcastToTenant(tenantId, "lead:converted", ...)`
2. **Asset Assignment (`server/src/routes/assets.routes.ts`)**:
   - Route: `POST /:id/assign` (available at `/api/assets/:id/assign` and `/api/addons/assets/:id/assign`)
   - Permissions: `requireAuth`
   - Allocates asset quantity to employee or department, creates `AssetAssignment` record, logs `AssetActivityLog`, and updates `Asset.availableQuantity`.
3. **Expense Approval (`server/src/routes/expenses.routes.ts`)**:
   - Route: `PUT /:id/approve` and `PUT /claims/:id/approve` (also supporting `POST /:id/approve`)
   - Permissions: `requireAuth`
   - Delegates to `approvalService.processApproval` with role mapping and audit logging.
4. **Tenant Resource Quota Management (`server/src/routes/super.routes.ts`)**:
   - Routes: `PUT /tenants/:id/quota` and `GET /tenants/:id/quota`
   - Permissions: `requireAuth`, `requireSuperAdmin`
   - Integrates `QuotaGovernanceService.setTenantQuotaOverride` and synchronizes `TenantSubscription.maxUsers` / `storageLimitGb`.
5. **Verification**:
   - Automated integration tests in `server/src/tests/missing-endpoints.test.ts`.
   - TypeScript compilation check (`npx tsc --noEmit`).
