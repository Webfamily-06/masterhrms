# Phase 12 Plan: Internal WorkDo Add-on Modules Verification (Wave 4: Operations, Finance & Strategy)

## Goal
Empirically verify 10 internal WorkDo reference add-on modules currently categorized as `PLANNED` across McKinsey 7-S Framework, Asset Borrow & Rent, Financial Goal, Retainer, Recurring Invoice & Bill, Team Workload, Time Tracker, Procurement, Petty Cash, and Signature by authoring and executing comprehensive native automated test suites (`node:test` + `node:assert/strict`), promoting all 10 items to `VERIFIED` (Milestone 7.7).

## Target Scope & Requirements

1. **REQ-W4-01 (`ADDON-066` - McKinsey 7-S Framework)**:
   - Provide template structure in `StrategyStudioService` with the 7 dimensions: Strategy, Structure, Systems, Shared Values, Style, Staff, Skills.
   - Matrix document authoring, quadrant/section item creation, impact scoring (1-5), and strategic model integration in `PlanningStrategyService` (type `mckinsey7s`).
   - Strict multi-tenant isolation.

2. **REQ-W4-02 (`ADDON-082` - Asset Borrow & Rent)**:
   - Asset borrow/loan request submission (`AssetRequest` in Prisma) with employee, item name, quantity, purpose, and priority.
   - Manager review and approval lifecycle (`pending` -> `approved`/`rejected`/`fulfilled`) with audit logging.
   - Strict multi-tenant isolation.

3. **REQ-W4-03 (`ADDON-083` - Financial Goal)**:
   - Financial goal creation using PostgreSQL `financial_goals` model with target amount, current progress, goal type (`revenue`, `savings`), and target dates.
   - Real-time progress updates, variance calculation, and status progression (`in_progress` -> `achieved`).
   - Strict multi-tenant isolation.

4. **REQ-W4-04 (`ADDON-084` - Retainer)**:
   - Retainer agreement lifecycle with client attribution, upfront advance balance, drawdown debit transactions, and status tracking (`ACTIVE`, `DEPLETED`).
   - Drawdown linking to project milestones and invoices.
   - Strict multi-tenant isolation.

5. **REQ-W4-05 (`ADDON-088` - Recurring Invoice & Bill)**:
   - Recurring invoice schedule evaluation (`recurring-invoice.service.ts`) with frequency calculation (`weekly`, `monthly`, `quarterly`, `yearly`).
   - Idempotent formal invoice (`Sale`) generation from recurring schedule.
   - Strict multi-tenant isolation.

6. **REQ-W4-06 (`ADDON-091` - Team Workload)**:
   - Aggregated employee workload calculation combining project task assignments and logged timesheet hours.
   - Over-allocation detection (> 40 hours standard capacity per week) and department team capacity reporting.
   - Strict multi-tenant isolation.

7. **REQ-W4-07 (`ADDON-092` - Time Tracker)**:
   - Active time tracker lifecycle: start timer for project/task, calculate active duration, stop timer.
   - Automatic generation/commit of formal `Timesheet` records into PostgreSQL.
   - Strict multi-tenant isolation.

8. **REQ-W4-08 (`ADDON-095` - Procurement)**:
   - Purchase order lifecycle (`Purchase` & `PurchaseDetail` in Prisma) with supplier, items, tax calculation, and warehouse allocation.
   - Order status progression (`draft` -> `ordered` -> `received`) and payment recording.
   - Strict multi-tenant isolation.

9. **REQ-W4-09 (`ADDON-097` - Petty Cash)**:
   - Cash register drawer shift lifecycle (`CashRegister` & `RegisterShift` in Prisma) with opening float.
   - Cash in and petty cash disbursement (`cashOut`) recording.
   - Shift closing with expected cash calculation, actual cash count, and variance auditing.
   - Strict multi-tenant isolation.

10. **REQ-W4-10 (`ADDON-121` - Signature)**:
    - Cryptographic digital signing via `DigitalSignatureService` using 2048-bit RSA keys and SHA-256 digest hashing.
    - Public key certificate verification and detached base64 signature validation.
    - Tamper detection rejecting altered content payloads.
