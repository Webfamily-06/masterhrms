# Plan 01-01: Wire Inactive Background Cron Workers to Server Startup Scheduler

## Objective
Wire the 4 previously inactive/orphaned cron workers into `server/src/index.ts` startup scheduling loop so they execute continuously on automated daily schedules with fail-closed error handling and tenant scoping:
- `document-expiry.cron`: sweeps expiring documents and notifies employees.
- `probation-contract-expiry.cron`: monitors probation milestones and expiring contracts.
- `reporting-manager-change.cron`: applies scheduled future-dated manager hierarchy transfers.
- `saas-billing.cron`: moves expired trials to `past_due` and enforces subscription grace periods.

## Acceptance Criteria
1. `server/src/index.ts` imports the cron worker functions.
2. Schedulers are initialized at server startup with proper daily UTC targets.
3. Errors in any one cron job are logged cleanly and do not crash the server process.
4. `npm run check:server` or TypeScript verification compiles with 0 errors.
