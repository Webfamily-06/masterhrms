# Phase 14 / Milestone 8.1 Plan: Social OAuth Sign-in & Identity Federation Suite

## Overview
Phase 14 transitions the external third-party matrix plugins (the remaining 47 items) by verifying and operationalizing the 6 core social login & single sign-on (SSO) identity federation add-ons:
- **ADDON-128**: GitHub Sign-in (OAuth)
- **ADDON-129**: Facebook Sign-in (OAuth)
- **ADDON-130**: Google Sign-in (OAuth)
- **ADDON-131**: LinkedIn Sign-in (OAuth)
- **ADDON-132**: Slack Sign-in (OAuth)
- **ADDON-133**: Microsoft Sign-in (OAuth)

## Key Technical Objectives
1. **Zero Secret Leakage**:
   - `OAuthFactory.getPublicConfig()` strictly exposes client identifiers and boolean flags (`enabled`, `configured`).
   - Client secrets, application secrets, and tenant secrets are AES-256 encrypted in the database and never exposed to the frontend.
2. **CSRF & State Security**:
   - Cryptographically random state parameter generation (`OAuthFactory.generateState`) with in-memory TTL and single-use invalidation (`OAuthFactory.validateState`).
3. **Pluggable Multi-Provider Support**:
   - Seamless routing for Google, GitHub, Microsoft Entra ID, LinkedIn, Facebook, and Slack OpenID Connect.
   - Dynamic settings persistence via authoritative `SettingsService` under `group: "oauth"` with instant cache invalidation.
4. **Automated User Provisioning & Session Issuance**:
   - Token exchange via provider token endpoints.
   - Profile payload parsing and normalization (`email`, `fullName`, `avatarUrl`).
   - Auto-provisioning of `User` and `Profile` in the relational database with multi-tenant `tenantId` assignment.
   - Issue signed JWT authentication tokens for immediate login session.

## Verification Matrix

- Full TypeScript compilation with zero errors across server and client.
