# Portal Screen-by-Screen Gap Matrix
**Forensic Inventory & Visual/Functional Discrepancy Matrix**

**Audit Standard:** Strict Source-of-Truth Comparison  
**Reference Laravel Codebases:** `main-file/resources/js/pages/`, `main-file/packages/workdo/*/src/Resources/js/Pages/`, `ui/`, `ui-2/`  
**Target React Codebase:** `src/routes/` and `src/components/`  
**Status Definitions:**
- **COMPLETE**: Screen visually and functionally mirrors the Laravel reference with full database persistence.
- **PARTIAL**: Screen is implemented, but missing specific sub-components, modal workflows, line-item repeaters, or secondary tabs.
- **DIFFERENT**: Screen exists but uses an entirely different layout, styling system, or navigation model compared to Laravel.
- **MISSING**: Screen exists in Laravel or template suites but has no corresponding route or implementation in the React application.
