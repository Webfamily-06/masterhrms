## 1. ARCHITECTURAL TOPOLOGY & ROUTING FRAMEWORK

MasterHRMS is built on a dual-stack full-cycle human resource management architecture comprising:
1. **Frontend Architecture:** Next.js / TanStack Router application located at `src/routes/` with three distinct authenticated operational views:
   - **HR Portal (`src/routes/_authenticated/hr/*`):** Specialized administrative screens for HR administrators, recruiters, and payroll operators.
   - **Employee Self-Service (ESS / ME Portal (`src/routes/_authenticated/me/*`)):** Scoped portal for individual employee requests, personal records, approvals, and team management.
   - **Enterprise Suite / Classic Workspace (`src/routes/_authenticated/_app/*`):** Unified ERP/HRMS workspaces covering financial operations, assets, CRM, commerce, and platform configuration.
2. **Backend API Architecture:** Node.js / Express server in `server/src/` with a dual routing tier:
   - **Platform Foundation Scoped Tier (`/api/v1/hr/*`, `/api/v1/me/*`):** Mounted via `server/src/routes/platform-foundation.routes.ts` with strict tenant and role context middleware.
   - **Classic Direct API Tier (`/api/employees`, `/api/attendance`, `/api/payroll`, etc.):** Mounted directly in `server/src/index.ts`.
3. **Database Layer:** Prisma ORM schema with 282 database models defined in `server/prisma/schema.prisma` targeting PostgreSQL.
4. **Desktop Edge Hardware Integration:** Electron / Node.js desktop daemon (`Bio-matric Software/desktop-app`) communicating via TCP socket port 4370 (`zklib-bridge.js`) to physical biometric devices and syncing over HTTPS to `/api/public/biometric/push`.

## 3. SUMMARY OF INVENTORY FINDINGS

- **Total Functional Modules Identified:** 26 modules.
- **Modules with Comprehensive Working Implementations (VERIFIED):** 11 modules (Organization, Shifts & Rosters, Bank Disbursement, Expenses & Advances, Transfers, Corporate Assets, Performance & OKRs, Training, Disciplinary, Announcements, Helpdesk).
- **Modules with Significant Operational or Validation Gaps (PARTIAL):** 15 modules (Recruitment, Pre-Onboarding, Employee Master, ESS, Attendance & Biometrics, Regularization, Leave Management, Advanced Payroll, Statutory Compliance, Tax Declarations, Lifecycle & Confirmation, Promotions, Separation & Offboarding, Full & Final Settlement).
- **Critical Architectural Duality Observed:** The presence of both legacy un-scoped endpoints (e.g., `PUT /api/employees/:id`) and scoped foundation endpoints (`PUT /api/v1/hr/employees/:id`) leads to authorization bypass vulnerabilities where permission and business validation checks implemented in newer service layers can be completely circumvented via the older routes.
